Hi, I'm Sanjay. I'm a 3rd-year CSE student at Amity University Rajasthan. I build AI agents, RAG systems and the backends behind them, then try to break them before anyone else does.

### Exploring

- **Agents with limits.** Retry caps, loop guards, compliance gates, and a human in the loop for risky calls.
- **Retrieval that admits defeat.** Grounded answers, citation checks, and handling documents that supersede each other.
- **Tool workflows.** Making MCP and LangChain tools behave when an LLM is the one calling them.
- **Traces over guesswork.** Reading the full run to see why an agent did what it did.

### Building

- FastAPI backends that carry state, retries and an audit trail.
- RAG over messy real documents: scanned PDFs, OCR, amendments.
- Small, readable code I can explain line by line.

### How I think

- A confident wrong answer is worse than "not found".
- An agent without limits is a liability. Cap it, gate it, and let a human decide the risky calls.
- If I can't trace it, I don't trust it.
